# ADR 0029 — Adaptive selection at fixture admission

Accepted for implementation on 2026-11-05 under
[ADR 0028](0028-reasoning-policy-and-execution-ownership.md). Independent
review and release acceptance remain separate.

## Decision

The finite and grounded profiles keep their existing baseline policies.
An explicitly installed adaptive host may calculate a recommendation from
validated local fixture state. Shadow runs execute their original plans.
Only the source-free finite profile has a candidate strategy eligible for
a local canary. The arithmetic workflow admits its distinct V2 template
under the original key, using the same row, fence, attempt resources,
context assembly and chat continuation.

Canary admission requires a trusted scope-specific fixture allowlist and
independently signed evidence bound to the exact policy, build, protocol,
endpoint, scope, family, effort and intersected limits. The local pointer
serializes policy publication and rollback with admissions. Submitted runs
keep their original approval and plan identity. Current execution authority
is checked at each canonical boundary.

Reserve both generations and both verifier operations before starting
the candidate template. A first objective check is required for safe early
exit. If an alternative runs, a single final comparison checks both
bounded vectors and merges only exact supported slots. Deterministic
selection is sufficient for this grammar, so synthesis consumes no
model call. Grounded citation and complete-result verification remain in
their existing profile.

## Consequences

The terminal adaptive receipt contains versioned redacted metadata.
Active typed checkpoints are cleaned at terminal transition. The workflow
retains original attempt bindings and does not retry an uncertain send.
A worker may resume an unexecuted optional step using its original child
identity and the remaining budget. This also limits retries of the pure
predicates to the existing conservative accounting rules.

The signed evidence mechanism is restricted to the local fixture. The
author-visible [experiment](../reasoning-engine/adaptive-experiment.md)
cannot satisfy its independent approval requirement. Local file locking
and native PostgreSQL fixture behavior do not establish distributed policy
publication, cloud restore, or provider and external source authority.
