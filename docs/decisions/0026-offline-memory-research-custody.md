# ADR 0026 — Offline memory experiment custody and decision authority

Accepted for bounded local E0/E1 development on 2026-11-04.

## Decision

Memory research owns immutable experiment identities, complete attempted grids,
longitudinal memory hypotheses and pure research decision proposals. Shared
context assembly, scoped memory services, source/lifecycle owners and the existing
hermetic task simulator retain their contracts. Shared inference/usage plumbing
continues to own model attempts and telemetry. Research supplies no dispatcher,
source grant, episode issuer, durable-memory writer or effective policy registry.

A sealed additive public/synthetic corpus separates source-only task trajectories
from scorer-only expectations. Policy consumers receive serialized context and
narrow task tools, without gold, split or fault labels. The host owns timeline
mutations; the scorer observes terminal state under a new original intent. Setup
success is never later task success. Every split is author-visible. A challenge
submission is validated but cannot install itself as a trusted corpus or certify
independent authorship. Different source schemas remain distinct cohorts;
incompatible comparators retain unsupported rows.

The protocol pins matched budgets, six contrasts, two replay repetitions and a
scenario-clustered descriptive bootstrap before measured trials. Resource counts
include setup, maintenance, failed attempts and explicit memory-tool lookups.
Fixture word estimates are separate from unobserved actual model tokens and
billed/native costs. Safety failures and unknown critical gates veto a decision;
unsupported pairs are never assigned zero task quality or omitted from attempts.

Bounded content-addressed local packages contain a run manifest, receipts,
reports and digest inventory. An append-only local decision chain retains failed
hypotheses and fences rejected evidence aliases. New evidence links prior failure.
Hashes detect drift relative to a retained anchor; they are not authentication,
signatures or rights. Replacing an entire package/chain and its external anchor is
outside this integrity claim. There is no independent signer or reviewer issuer.
The compact 30-day scoped `research_experiments` table remains unchanged; it does
not become an archive or promotion database. Local artifacts are disposable
synthetic evidence, never a second lifecycle for owner data.

The pure decision evaluator requires host-attested report custody and a distinct
trusted reviewer for an offline canary proposal. No JSON field can instantiate
that authority. A canary planner re-evaluates the report and exact rollback target;
its sample stages, stop conditions and monitors cannot be lowered by imported
manifests. Canary and rollback functions return plans only. There is no live
execution path. Protocol-only model metadata is representable, but executable
runs reject it and permit only the scripted no-transport model space.

## Consequences

Fresh-process verification checks package hashes, current source identities,
complete rows, scorer custody and a new two-repetition semantic replay. Timings
are preserved in receipts and excluded from semantic equality. Source changes
require a new additive evidence generation; predecessor locks are not rebound.
The initial source anchor excludes itself from hash recursion and is separately
included in each run manifest. Environment/model/configuration mismatches fail
closed; host environment flags do not configure synthetic experiments.

This establishes author-reported E0/E1 research plumbing only. Independent blind
challenge/scorer custody, installed native durability, deployed permission and
forget/restore authority, physical sends, resource/cost observations and real-model
longitudinal utility remain separate evidence gates. All runtime defaults and
prior release restrictions remain effective. No experiment can approve live
promotion, including one with positive synthetic utility.
