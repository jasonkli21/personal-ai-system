# Grounded reasoning release gates

E0/E1 is a development candidate with local synthetic measurement. Native
PostgreSQL observations apply to the specific workflow tests listed in the
[verification report](re-3-verification.md). Independent review of the exact
commit is pending. The integrated native target retains inherited failures.

| Tier or gate | Disposition | Evidence still required |
| --- | --- | --- |
| E1 independent acceptance | Open | Reproduce the sealed evaluation, review the exact diff and attempt to falsify source, receipt and recovery claims. The held-out split is authored synthetic data. |
| E2 installed model and native acceptance | Partial | The disposable native store exercises grounded reads, receipts, fencing and process-loss recovery. The combined target still has two pinned-baseline cancellation assertions. Real installed-model admission, output, tokenizer, latency and accounting are unverified. |
| E3 live source and provider | Blocked | PI-5 remains `blocked_unverified`. An issuer-bound monotonic rights lease, exact atomic physical-send permit, approved account and independent provider reservation, quota and settlement evidence are required. HXE-1's partial fixture evidence grants no live authority. |
| E4 deployment and restore | Blocked | Verify private invocation and identity, distributed source revocation, anti-rollback original keys and attempt receipts, restore, retention and deletion in an independently authorized topology. Restoring an earlier workflow database and matching source/authority state together can roll back local observations. |
| E5 real task quality | Blocked | Use independently held-out tasks, authorized real-model evaluation and human or objective scoring at matched resource ceilings. The current narrow fact grammar and synthetic retrieval layout measure a scripted effect. |

The grounded host and fixture callback are current local authority checks.
They cannot synchronize an external issuer's revocation with a physical send.
The profile has no public HTTP or SDK entry point. External retrieval, live
model sends and memory episode export remain disabled for this profile.
