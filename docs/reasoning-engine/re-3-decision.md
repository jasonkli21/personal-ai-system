# Grounded reasoning development profile

This decision applies ADR 0028 at E0/E1. Entry was
`4e28b433ea1a0b129701d6da9cf6560f1ea80f9a`, tree
`f3220eba98e07f80ca00df1e905dcb7976fb142f`. The PRD move and planning
files were already present as working-tree changes.

Use a separate `reasoning-grounded-request-v1` and
`reasoning-grounded-plan-v1` with the closed
`evidence-research-bounded.v1` strategy. WorkflowService and its existing
PostgreSQL row own intent, fences, events, attempts, cancellation and replay.
The finite source-free plan and verifier recovery contract retain their
existing meanings.

A trusted foreground host explicitly opts in and pins an authorized,
public synthetic v2 installation. The retrieval tool reads that exact
installation. A request-local context provider supplies already-retrieved
items to the canonical assembler under existing model-context grants.
The only inference endpoint is the credential-free in-process fixture.
Check source and context permissions at use and disclosure boundaries.
PI-5 issuer, atomic send, accounting and rollback gates remain open.

Use one initial query and reserve synthesis and verification before spending
an optional second query on one measurable slot. Evidence and candidate
values live in the claiming process. If that process is lost after a completed
step, a later claim stops without fetching or reconstructing the lost data.
Unknown dispatched operations retain their original bindings. Only typed
source metadata and bounded observations survive terminalization.
