# Local ChatGPT account controls and synthetic inference bridge

`python -m personal_ai.local_bridge` opens the local account controller. It supports `sign-in`, `reauth CONNECTION`, `status`, `sign-out CONNECTION`, and `quit`. Sign-in and reauthorization request identity scopes and use an ephemeral callback on `127.0.0.1`. Status reports local account state and a safe account label. Sign-out clears credentials locally before it attempts remote revocation and reports whether revocation was confirmed. The optional `--directory` selects a private POSIX directory outside any repository. [Manage your ChatGPT account](https://chatgpt.com/), [ChatGPT plan and app usage controls](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites).

Live plan inference is disabled. The account controller starts no execution listener, and local configuration files confer no execution authority. PAS's normal execution options exclude the SIWC text profile. The standalone loopback app and the Responses client are exercised with injected transports in tests.

The synthetic composition admits one local PAS chat installation. Trusted code pins an exact loopback origin, host and runtime, issuer and signing key, PAS owner, actor and workspace, and an approved OpenAI registration and revision. PAS's issuer signs one foreground, source-free package after shared context assembly and canonical reservation checks. The grant may cover active conversation history. App-source context, inherited source dependencies, memory and background use are outside this profile.

The bridge checks the exact account-visible model and rechecks the pairing, proof, profile and credential under the durable send-start lock. A successful stream requires a matching Responses terminal and a durable receipt. Reconciliation returns safe status without response text. Acknowledged or expired receipts compact to non-resend fences. When authorization changes after the local commit, a request may already reach the transport. An uncertain outcome retains its fence and receives no automatic resend or fallback.
