# Security

This repository is experimental and is not approved for production use with personal data. Local identity, fake providers, synthetic authorization, and offline tests do not establish deployed security. See [current state](docs/current-state.md) for open gates.

## Reporting a vulnerability

Please do not publish credentials, personal data, or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, contact a repository maintainer through an existing private channel before sharing technical details. No dedicated security email or response-time commitment is currently provided.

Include the affected revision, impact, conditions needed to reproduce, and a minimal reproduction without real credentials or personal data. Allow maintainers time to investigate before public disclosure.
